# Jólabjórar

A small static site for browsing the Christmas beers (*jólabjórar*) sold by Vínbúðin, Iceland's state liquor store, for the 2026 season. The interface is in Icelandic.

## Features

- Free-text search across name, producer and description
- Filters by beer type, producer and country of origin
- Sorting by name, price, ABV, country or producer, ascending or descending
- Availability filter for the Akranes, Keflavík (Reykjanesbær), Selfoss and Vestmannaeyjar stores
- One card per product, with an image, tasting notes, price and a link to the product page on vinbudin.is

## Running it

The site has no build step and no dependencies. Open `index.html` in a browser, or serve the folder:

```sh
npx serve .
# or
python3 -m http.server
```

## Project structure

| File          | Purpose                                                                 |
| ------------- | ----------------------------------------------------------------------- |
| `index.html`  | Page markup, filter controls and the product card template              |
| `app.js`      | Fills the filter dropdowns, then filters, sorts and renders the cards   |
| `styles.css`  | Styling, including responsive layouts for tablet and phone widths       |
| `data.js`     | Product data, assigned to `window.beers` (generated by `scrape.mjs`)    |
| `scrape.mjs`  | Script that fetches product details from vinbudin.is                    |

## Updating the data

`data.js` is generated and updated by hand. To refresh prices and availability, run the scraper with Node 18 or newer (it needs the built-in `fetch`):

```sh
node scrape.mjs
```

The script fetches each product page listed in the `ids` string at the top of `scrape.mjs` and overwrites `data.js`. It fetches one page at a time with a short pause in between, and backs off and retries when the server rate-limits it (HTTP 429), so a full run takes a few minutes. To add or remove a beer, edit that list of Vínbúðin product numbers and run the script again.

Each product record looks like this:

```json
{
  "id": "30871",
  "name": "Kaldi Litlu jól (30871)",
  "price": 432,
  "abv": "4,4",
  "country": "Ísland",
  "producer": "Bruggsmiðjan Kaldi ehf.",
  "description": "Rafgullinn. Ósætur, léttur, meðalbeiskja. …",
  "category": "Bjór",
  "type": "Ljós lager — Léttur lager",
  "availability": { "Akranes": true, "Keflavík": true, "Selfoss": true, "Vestmannaeyjar": true },
  "image": "https://www.vinbudin.is/Portaldata/1/Resources/vorumyndir/medium/30871_r.jpg",
  "source": "https://www.vinbudin.is/desktopdefault.aspx/tabid-54/?productid=30871/"
}
```

`price` is in Icelandic krónur. `abv` is a string with a decimal comma, as shown on the source site.

The scraper reads specific element IDs and class names from Vínbúðin's HTML. If the site's markup changes and a product's name, price or ABV comes back empty, the script exits with an error and leaves `data.js` as it was.

After a run, commit and push `data.js`. GitHub Pages then redeploys the site.
